# 🎓 University Projects - Computer Engineering

## 📌 Description
This repository was created to organize, store, and document the work done during my university years. It specifically contains the academic projects developed for courses where they were required or offered as an optional assignment.

The primary goal is to keep track of my technical growth and to maintain a personal history of my university projects that is always accessible online and publicly available to analyze, study and learn from.
